# SEUNGA'S ROOM — 서승아의 외출 준비

서승아의 FocusAI(2025)와 CARELINK(2026), 두 번의 1년을 연결하는 3D 게임형 개인 포트폴리오입니다. 활동 물건 여섯 개를 찾아 경험을 가방에 챙기면 다음 꿈을 향해 출발하는 엔딩을 볼 수 있습니다.

## 실행

정적 웹사이트입니다. 이 폴더를 HTTP 서버로 열거나 GitHub Pages에 배포하세요. 로컬에서는 `python3 -m http.server 8765`로 열 수 있습니다. 모듈을 사용하므로 파일을 더블클릭하는 방식 대신 HTTP 서버가 필요합니다.

## 수정

- `data.js`: 활동 소개, 역할, 성과, 에피소드
- `scene.js`: 3D 방, 캐릭터와 물건, 애니메이션
- `style.css`: 화면 구성과 반응형 스타일
- `app.js`: 수집 상태, 경험 노트와 엔딩

실제 활동과 사용자가 제공한 경험에 근거해 작성했습니다. 활동 소품과 3D 장면은 경험을 표현하기 위한 연출입니다. 캐릭터 몸은 기하 모델로 구현했고, 얼굴은 사용자가 제공한 음뽀챠무 사진의 원본 표정을 3D 표면에 투영합니다. 원본 사진은 수정하지 않고 포함했으며 얼굴 영역만 화면에 표시합니다. 공식 캐릭터 모델이나 공식 협업 사이트가 아닙니다.

수집 상태는 브라우저의 localStorage에 저장됩니다. 경험 노트에서 초기화할 수 있으며 방문자 데이터 전송이나 계정 기능은 없습니다. 3D가 지원되지 않는 환경에서도 경험 노트와 가방을 통해 전체 내용을 읽을 수 있습니다.

Three.js r160(MIT)을 `assets/three.module.js`에 포함했습니다. 글꼴은 Google Fonts의 Noto Sans KR을 사용하며, 연결이 없을 때는 시스템 고딕체로 표시됩니다.
