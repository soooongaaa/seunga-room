# SEUNGA'S ROOM — 서승아의 외출 준비

전공에 자신도 뚜렷한 꿈도 없던 서승아가 FocusAI(2025)와 CARELINK(2026)를 통해 자신감과 창업의 꿈, 도전할 열정을 찾아가는 개인 포트폴리오입니다. 첫 화면의 3D 방과 함께, 대표 프로젝트 → 다른 경험 → 소개 순서로 내용을 바로 읽을 수 있습니다. 활동 물건 여섯 개를 찾아 경험을 가방에 챙기면 찾은 꿈을 향해 출발하는 엔딩을 볼 수 있습니다.

각 프로젝트와 경험은 개요·기간·역할, 발견한 문제, 접근 방법, 개인 기여, 산출물과 성과, 배운 점으로 구성됩니다. 대표 프로젝트의 흐름도는 서비스의 기획 구조를 설명하며 실제 제품 화면이나 성과 수치를 대신하지 않습니다.

## 실행

정적 웹사이트입니다. 이 폴더를 HTTP 서버로 열거나 GitHub Pages에 배포하세요. 로컬에서는 `python3 -m http.server 8765`로 열 수 있습니다. 모듈을 사용하므로 파일을 더블클릭하는 방식 대신 HTTP 서버가 필요합니다.

## 수정

- `data.js`: 활동 개요, 기간·역할, 문제·접근, 개인 기여, 산출물·성과, 배운 점
- `scene.js`: 3D 방, 캐릭터와 물건, 애니메이션
- `npochamu.js`: 원본 사진을 사용하는 캐릭터, 정면 표시와 대기 자세
- `style.css`: 화면 구성과 반응형 스타일
- `app.js`: 프로젝트 목록과 상세, 수집 상태, 전체 목록과 엔딩

실제 활동과 사용자가 제공한 경험에 근거해 작성했습니다. 수상은 각 프로젝트의 상세 성과 목록에 한 번씩만 기재하고, 소개와 엔딩은 자신감·꿈·도전의 변화를 중심으로 구성합니다. CARELINK 수상명은 2026 경기SW 페스타 대상입니다. 활동 소품과 3D 장면은 경험을 표현하기 위한 연출입니다. 캐릭터는 사용자가 제공한 고해상도 사진 자체를 사용합니다. 사진은 수정 없이 보관하고, 웹 화면에서 캐릭터 영역만 표시해 외형을 유지합니다. 방은 3D이며 캐릭터는 카메라를 향하는 사진 기반 표현입니다. 독립적인 입체 캐릭터 모델이 아닙니다. 기본 자세에는 첫 번째 사진, 대기 자세에는 두 번째 사진을 사용합니다. 공식 협업 사이트가 아닙니다.

수집 상태는 브라우저의 localStorage에 저장됩니다. ‘전체 보기’의 게임 가방 초기화로 지울 수 있으며 방문자 데이터 전송이나 계정 기능은 없습니다. 3D가 지원되지 않는 환경에서도 프로젝트 목록, 전체 보기, 가방을 통해 내용을 읽을 수 있습니다.

Three.js r160(MIT)을 `assets/three.module.js`에 포함했습니다. 글꼴은 Google Fonts의 Noto Sans KR을 사용하며, 연결이 없을 때는 시스템 고딕체로 표시됩니다.
